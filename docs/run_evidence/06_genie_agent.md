## Q7. Which data-quality check found the most issues on the latest report date?

**Result: ✅ PASS** · expected `pii_in_free_text`

> Genie: You want to see which data-quality check found the highest number of issues on the most recent report date. On the latest report date, **peril_mismatch** and **pii_in_free_text** found the **most issues**, tied at **4** each. Both were **High** severity checks, each reviewed **148** records with a **97.3%** pass rate, so the highest issue count was shared rather than driven by a single check.

<details><summary>SQL generated by Genie</summary>

```sql
WITH `latest_date` AS (
  SELECT MAX(`report_date`) AS `report_date`
  FROM `<catalog>`.`loss_ratio_coworker`.`dq_daily_scorecard`
), `ranked_checks` AS (
  SELECT
    `check_name`,
    `check_type`,
    `severity`,
    `issues`,
    `records_checked`,
    `pass_rate`,
    RANK() OVER (ORDER BY `issues` DESC) AS `issue_rank`
  FROM `<catalog>`.`loss_ratio_coworker`.`dq_daily_scorecard`
  WHERE `report_date` = (SELECT `report_date` FROM `latest_date`)
    AND `issues` IS NOT NULL
    AND `check_name` IS NOT NULL
)
SELECT
  `check_name`,
  `check_type`,
  `severity`,
  `issues`,
  `records_checked`,
  `pass_rate`
FROM `ranked_checks`
WHERE `issue_rank` <= 1
ORDER BY `issues` DESC, `check_name` ASC
```
